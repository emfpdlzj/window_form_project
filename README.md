#  window_form_project  
**.NET 프레임워크-윈도우폼을 이용한 프로젝트 모음**

2025년 부터 IT회사에서 장학 인턴을 하며 제작한 실사용 프로그램들을 정리한 저장소입니다.  
모든 프로젝트는 **C#과 WinForms**를 기반으로 구현되었으며, 실제 업무에서 반복되는 작업을 자동화하고 효율화하는 데 목적을 두고 있습니다.

---

##  프로젝트 목록

### 1.  로고 자동 삽입 프로그램
> **Word 문서에 표지/머리말 로고를 자동으로 삽입해주는 프로그램**

- `.docx` 파일을 선택하면, 사용자가 선택한 이미지(로고)를 문서의 **첫 페이지 표지**와 **머리말**에 자동으로 배치합니다.
- 반복적인 문서 작업을 자동화하여 업무 효율성을 높입니다.

### 2.  그래프 자동 생성 프로그램
> **CSV 또는 텍스트 파일 기반 노드 그래프를 시각화하는 도구**

- 좌표 데이터가 담긴 `.csv` 또는 `.txt` 파일을 불러와 **노드 그래프를 자동으로 생성**합니다.
- 노드 간 연결, 미니맵, 패닝/줌 등의 기능을 지원하며, 결과 이미지를 `.png`로 저장할 수 있습니다.

---

##  기술 스택
- C# (.NET Framework)
- Windows Forms (WinForms)
- Microsoft.Office.Interop.Word (문서 자동화)
- System.Drawing (GDI+ 기반 시각화)
