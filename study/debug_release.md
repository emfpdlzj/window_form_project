# 디버그와 릴리즈 버전의 차이

---
Debug 모드: 디버깅에 적합한 빌드. 개발이 진행중인 프로젝트에서 개발자가 디버깅시 사용
Release 모드: 배포에 적합한 빌드. 개발이 완료되고, 실제 사용자에게 전달할 때 사용 권장.

**Debug**
- 코드 최적화를 하지 않는다
- 바이너리(실행 파일)크기가 크다.
- 코드 실행속도가 느리다
- 메모리 사용량이 많다
- 바이너리에 디버깅에 필요한 정보가 포함되어있다.
- 컴파일 속도가 빠르다.


**Release**
- 코드 최적화 과정을 수행한다
- 바이너리 크기가 작다
- 코드 실행속도가 빠르다
- 메모리 사용량이 적다
- 디버깅에 필요한 정보가 거의 포함되지 않는다
- 최적화 과정이 포함되어, 컴파일 속도가 느리다.

Release 빌드에서도 Debug빌드에서 확인되지 않은 문제점이 발견되므로, Release 빌드에서의 테스트도 필수이다.
